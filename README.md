# WELCOME TO FOOTYHUB

FootyHub is a basic dashboard, for you to follow your favorite team!

## Features

* Top 5 Leagues with all included teams
* Easy description and info on your favourite team
* EzMemory


## Installation

```bash
git clone https://github.com/username/repository.git
cd repository
npm install
npm run dev
```

## Usage

Use it to follow your favorite team, and maybe find out some cool facts!
